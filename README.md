# Simple Theme Login Site Generator

A dynamic login page generator that allows users to customize colors, gradients, and button styles in real-time. This tool lets you preview and export a complete login interface with HTML, CSS, and JavaScript all in one place.

## 🚀 Live Demo

Check out the live demo: [https://www.xn--msiu-goa8b.vn/github/simple-theme-login-site-generator](https://www.xn--msiu-goa8b.vn/github/simple-theme-login-site-generator)

## ✨ Features

- **Real-time Customization** – Adjust gradient angles, background colors, button styles, and text colors on the fly
- **Live Preview** – See changes instantly as you tweak the settings
- **One-Click Export** – Copy generated HTML, CSS, and JavaScript code with a single click
- **Interactive Login Form** – Includes username, password, "Remember Me" checkbox, and password visibility toggle
- **Responsive Design** – Works seamlessly on desktop, tablet, and mobile devices
- **Clean UI** – Modern, user-friendly interface with smooth transitions

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)

## 🔧 Installation & Usage

1. **Clone the repository**
   ```bash
   git clone https://github.com/lemasieu/simple-theme-login-site-generator.git
   ```
2. **Navigate to the project folder**
   ```bash
   cd simple-theme-login-site-generator
   ```
3. **Open the application**
- Simply open `index.html` in your web browser
- Or use a local development server (e.g., Live Server in VS Code)

## 📝 How It Works

1. **Customize the Theme** – Use the input fields to adjust:
- Gradient angle and colors for the background
- Button colors (normal and hover states)
- Text colors for the login button and links
2. **Preview when submit** – The login form updates instantly as you press submit
3. **Export the Code** – Click the copy buttons to grab the generated HTML, CSS, or JavaScript and use them in your own project
4. **Test the Login** – The form includes basic validation and a success message simulation
